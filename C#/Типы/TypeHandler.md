Это специальное поле у любого объекта в куче, которое указывает какого типа объект хранится в куче.

Например:

class A { } class B : A { }

A obj = new B(); // в куче объект B

На стеке происходит выделение нового адреса, который будет содержать ссылку на адрес в куче, у которого TypeHandler = B, но мы должны где - то запомнить, что obj имеет тип A. Компилятор генерирует IL код, в котором это указано. В итоге это попадает в специальную кучу JIT, которая имеет информацию какая какой тип имеет. Это нужно для GC.
