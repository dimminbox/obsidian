
Это расширения метода для LINQ - AsParaller и другие методы. Это декларативный параллелизм, т.е. то когда программист декларирует что хочет получить а не управляет параллелизмом. Не гарантирует порядок обработки элементов.

По сути это насдстройка над LINQ для параллелизма.

AsParaller возвращает ParallerIEnumarable, который имеет следующие методы:
- WithDegreeOfParallelism(count) - количество потоков
- AsOrdered - гарантия порядка оригинальной коллекции
- ForAll - парарллельное действие без результата

Преимущества:
- Подходит для распараллеливания сложный вычислений
- Нужен результат в виде коллекции 
- Подходит только для больших коллекций т.к. для обработки берутся потоки из ThreadPool и нужно их синхронизировать, разбивать коллекцию на части чтобы параллельно обрабатывать.  Это всё достаточно накладно. Также как и для [[Parallel]]
- Не нужно общее состояние
