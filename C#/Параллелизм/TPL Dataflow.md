
Механизм, который реализует конвейер по обработке данных. Конвейер может состоять из комбинации следующих блоков:

-  BufferBlock Хранит элементы и отдаёт по запросу. Хранилище элементов
-  TransformBlocks. Блоки, который изменяют данные.
	  TransformManyBlock  отдаёт много результатов на один элемент
	  TransformBlock отдаёт один результат на один элемент
	  BatchBlock отдаёт один массив на несколько элементов
-  ActionBlock выполняет какие - то действия и ничего не отправляет
-  BroadcastBlock отправляет элемент всем подключенным блокам
-  JoinBlock ждёт под одному элементу из каждого источника и возвращает кортеж

Все блоки связываются через метод LinkTo. Данные автоматически текут между блоками. Когда мы вызываем метод Complete(), то даём понять блоку, что данных больше нет, то второй, т.е. зависящий от  него блок, тоже завершится, потому что ждать нечего.
Эта опция называется PropagateCompletion.

Также есть ограничение очереди между блоками, чтобы не было переполнения. Если слудующий блок не успевает, то предидущий ждёт. Это назвается backpressure.
