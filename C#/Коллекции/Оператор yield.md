Нужен для того, чтобы экономить память при работе с колллекцими. А именно он возвращает по одному элементу по запросу вместо того чтобы возвратить сразу все как это было бы без него. 

Ключевая особенность этого оператора - это использование state-machine под копотом. 
А именно, после первого вызова yield return мы запомнили state и дальше будем код с того места где остановились.  По факту компилятор генерирует целый класс Enumerator когда видит этот оператор, где MoveNext - реализация state machine а также метод Reset, свойство Current. По сути это генерация особенного энумератора.

Таким образом нам не нужно хранить всю коллекцию в памяти чтобы её перебрать, мы будем перебирать её по одному элементу. 

Также он обладает функцией ленивого выполнения, то есть при его создании ничего не выполнится, выполнится только тогда когда мы обратимся к элементу коллекции. LINQ работает на его основе, возращая результат только тогда когда выполняются методы Take, ToList, First и т.д. Это называется отложенное выполнение.

Он часто используется в методах расширения IEnumarable<T>
