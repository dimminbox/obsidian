В C# есть синтаксический сахар foreach который подразумевает передачу в него некоторого объекта, который должен удовлетворять оперделённым условиям. Допустим, что этим условием было бы то, что он должен был реализовывать интерфейс IEnumerable. Это значило бы, что было бы необходимо передавать только такой объект, а это неудобно. Для решения проблемы была призвана утиная типизация, которая подразумевает, что объект может не реализовывать необходимы интерфейс однако он должен содержать метод GetEnumerator() который возвращал бы объект с публичным методом bool MoveNext() и свойством object Current:

public struct FibonacciSequence  
{  
    public FibonacciSequenceEnumerator GetEnumerator()  
    {       
	     return new FibonacciSequenceEnumerator();  
    }}  
  
public struct FibonacciSequenceEnumerator  
{  
    public int Current { get; private set; }
    private int? _previous;  
	public void Dispose()  	{      } //вызывается в finally foreach, например, если foreach читает файл
     public bool MoveNext()  
    {   
	    if (Current == 0)  
        {
             Current = 1;  
            _previous = 0;  
        }
        else  
        {  
            var temp = Current;  
            Current += _previous;  
            _previous = temp;  
        }  
        return true;  
    }  
    public void Reset()  
    { 
           Сurrent = 0;  
        _previous = 0;  
    }}
}

Вместо реализиции классом FibonacciSequence интерфейса IEnumerable<int>
Это нарушает классический полиморфизм, но даёт возможность передавать туда что угодно, не имплементируя интерфейс (утиная типизация). Более того при реализации IEnumarable нам необходимо было бы использовать свойство Current типа object, поэтому при каждом обращении к нему происходил бы упаковка/распаковка. 

Более того мы можем использовать структуру то есть не аллоцировать память вовсе! В противном бы случае если бы структура реализовывала интерфейс, то при приведении к нему происходил бы боксинг структуры в объект.

Утиную типизацию можно встретить также в async/await - метод GetAwaiter(), IDisposable - Dispose().
