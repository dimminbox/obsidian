#### IEnumerable

Интерфейс,  который реализует метод ToList и  выполнение происходит в памяти приложения.

Методы Where, Single и прочие - это статические методы расширения интерфейса IEnumerable

IEnumable<out T> ковариантен

#### IAsyncEnumarable

Тот же IEnumarable но только отдаёт элементы по одному за счёт использования yield return. При его использовании мы читаем элементы по одному , т.е. вся коллекция из которой мы читаем не размещается в памяти целиком, что предотвращает большую аллокацию памяти. Но при использовании IAsyncEnumarable мы аллоцируем память под каждый элемент, т.е. нагружаем GC, который должен всё это чистить. 

Кроме этого есть недостатки:
-   нельзя читать несколько раз одну и туже коллекцию, это приводит к повторному запросу
-   нельзя обратится к элементу по индексу 
-   нельзя посчитать общее количество элементов
  
IEnumerable требует реализовать метод GetEnumarator, то есть класс, который должен реализовать следующее:
- bool MoveNext() - передвинуть указать на следующий элемент
- object Current get; - свойство, которое хранит текущий элемент
- void Reset() - сброс на первый элемент

#### IQuerable 

Это унаследованный от IEnumarable интерфейс со перегруженными методами типа ToList где происходит составление sql запроса используя дерево выражений (expression tree) и рефлексию через рефлексию и сам запрос выполняется на БД.

####IComparable<T> содержит метод CompareTo для сравнения объектов, какой больше или какой меньше

####IEquantable<T> содержит метод Equals(obj), который реализует операцию равенства между объектами.
