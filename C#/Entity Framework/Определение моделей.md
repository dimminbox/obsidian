
Модели можно определить через Data Annotations т.е. через аттрибуты у свойств класса или record, например, [Required, MaxLength(100)] или [Key]

Можно определить через Fluent Api внутри DBContext в методе OnModelCreating(), например

modelBuilder.Entity<User>() .Property(u => u.Name) .IsRequired() .HasMaxLength(100);
