EFCore использует IQuerable, который строит по дереву выражений (expression tree) SQL запрос, но выполняет его, когда вызван один из методов материлизации коллекции через Linq

Для загрузки сущностей из БД можно использовать различные методы:
- Lazy Loading который при обращении к навигационному полю внутри сущности делает соответствующий запрос к другой сущности, например, Order.Products сделает запрос к Products. Это порождает проблему n+1 запроса т.к. на каждую сущность будет выполняться +1 запрос
- Eager Loading, делает один большой запрос, доставкая сразу все данные, например, 
  context.Users.Include(u => u.Orders).ToList();
- Explicit Loading делает загрузку дополнительной сущности вручную, т.е. по требованию:
	`var user = context.Users.First();`
	`context.Entry(user).Collection(u => u.Orders).Load();
