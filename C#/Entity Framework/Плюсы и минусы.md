
Плюсы:

- не нужно строить запросы sql
- не нужно вручную сохранять данные в sql, т.е. делать update/insert/delete т.к. за это отвественен специальный механизм (tracking) который следит за изменениями сущности и когда мы её сохраняем, он сверяет её состояние до изменений и после и генерирует запросы. Но его можно отключить через AsNoTracking()
- Linq вместо строк SQL делает запрос типобезопасным т.к. ошибка в имени поля приводит к ошибке в компиляции в не в runtime.
- независимость от конкретной СУБД
- миграции на борту
  

Минусы:

- создаёт значительный оверхед из - за использования трекинга изменений, поэтому AsNoTracking даёт значительный прирост при read-only операциях
- невозможно описать через Linq сложные запросы поэтому всё равно приходится это делать через raw sql
- маетрилизация в DTO тоже не бесплатная и создаёт нагрузку, которая больше если бы мы сами мапили поля
