
У EFCore есть описанная модель, в папке Migrations находится актуальный снэпшот модели, который описывает как выгнлядеда модель на момент последней миграции.

При команде dotnet ef migrations add MigrationName Efcore проверяет изменения которые появлись с моделями и записывает новую миграцию, которая выглядит как класс с методами Up, Down.

При вызове команды dotnet ef database update (или програмно через dbContext.Migrate.Update() )происходит накатывание миграций на БД. При этом идёт также запись в специальную таблицу где хранятся уже выполненные миграции чтобы знать какие миграции ещё не применились.
