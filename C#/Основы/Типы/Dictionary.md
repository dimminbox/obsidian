
Хранит внутри себя массив бакетов (buckets) и массив записей (entries). 
Bucket хранит ссылки на entries. Entries хранит структуру состоящую из хеш кода элемента, значения и индекса следующей записи (при возникновении коллизий).

При добавлении элемента происодит:
- вычисление функции GetHashCode()
- по хэшу происходит вычисление индекса bucket
- по индексу бакета идёт проверка - ссылается ли он он уже на элемента  entry. Если да, то это означает что уже существует элемент в  в тем же самым посчитанным значением индексом бакета по hash функции и это называется коллизиец.  Поэтому текущий элемент добавляется в конец связанного списка. В итоге получается, что бакет указаывает на голову связанного списка. 
  
  Entities хранит hash код чтобы при увеличении bucket (если метос кончилось) нужно заново пересчитывать индексы а для этого нужно значение хэш-функции.
