
Список - это ссылочный тип, который хранится в куче. Внутри использует массив. Сложности:
- Доступ по индексу - O(1)
- Поиск по значению - O(n)
- Добавление в конец 0(1) но если нужно увеличить размер, то O(n)
- Добавление в начало или в середину - O(n)

Это потоконебезопасный тип поэтому для потокобезопасности требуется [[Concurrent#ConcurrentBag <T>]] .

Когда начинается перебор коллекции, то создаётся Enumerator через метод GenEnumerator(), который сохраняет внутри себя версию коллекции _version в отдельное поле. _version - это специльальное поле у коллекции которое обозначает версию коллекции. Когда происходит изменение коллекции _version меняется. Если во время работы Enumerator  выполняется метод MoveNext, который всякий раз проверяет version у коллекции и если он изменился, то выбрасывается исключение. Но бывается так, когда этот version одновременно и читают и пишут, т.е. проихсодит race condition, т.е. состояние List становится неуправляемым. Кроме того возникает гонка ещё на _items (самих элементах). Именно по этой причине List не безопасен для многопочгного использования.
