
Value types - типы, которые хранятся на стеке (примитивы int, bool, datetime, struct). Значения этих типов могут распологаться в куче если они являются частью объектов ref-types.

Reference types - эти типы, значения которых расположены в куче (массивы, классы, строки)

При передачи объекта ссылочного типа в метод в нём создаётся локальная копия ссылки на объект ссылочного типа. По ней мы можем его менять, но если эту ссылку приравнять к другой сссылке на другой объект, то внешний объект не изменится, т.к. ссылка внутри метода - локальная. 

При передаче в метод со словом ref мы передём ссылку на переменную и необходимо чтобы она УЖЕ была инициализирована.

При передаче out в метод мы можем НЕ инициализировать переменную, метод сам её либо инициализирует перед выходом либо перезапишет.

При передачи переменной с In мы передёт ссылку на переменную, по которой мы не можем её изменить в методе, т.е. она read only.
