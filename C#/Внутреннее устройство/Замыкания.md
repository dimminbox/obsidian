Когда мы вызываем делагат с параметрами мы передаём ему значения и он копирует их на стек и продолжает работать. Но что если делегату нужно получить доступ до внешних переменных без явной передачи их. Получается что нам нужно как - то связать наш делегат с внешней переменной. Для этого и существуют замыкания. 

Замыкания - это специальный механизм, который хранят состояние (значения локальных переменных) даже после повторного запуска. 
static Func<int> CreateCounter()
{

	int count = 0; // Локальная переменная
	// Возвращаем лямбду, которая "захватывает" count
	return () => ++count;
}

Это пример замыкания. 

Когда компилятор видит подобную ситуацию он генерирует класс и объект класса лежит в куче. Метод возвращает лямбду и в этом случае count создаётся как поле класса в куче.

 private class Closure { 
	  public int x; // захваченная переменная 
	  public bool Invoke(int n) => n > x;  //наш делегат
 }


Используется для:

-  LINQ (захват внешних переменных),
-  создаём одну функцию GreatherThan(int x), в которую можно передать разный x а не писать под каждое условие отдельную функцию
-  для использования колбэков, которые помнят значения переменных, которые в него передали, то есть функция захватывает переменные из внешнего контекста
  
  При использовании for в версии языка до C# 5+ внутри него лямбды захватывли внешние переменные, после 5 версии внутри for для каждой лямбды создаётся своя копия переменной.
