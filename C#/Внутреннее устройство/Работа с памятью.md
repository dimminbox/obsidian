Приложение при запуске потребляет память, которую можно разделить на следующие части:
1. Нативная память. Сюда входит:
   - стек
   - JIT - код
   - методанные рантайма, например  [[Таблица виртуальных адресов (vptr)]], служебные структуры сборщика мусора, подключаемые dll библиотеки
   - буферы внешних библиотек, например, буфер для redis, openssl
   - файловый кеш, т.е. при повторном чтении файла чтение просходит из памяти а не из диска
   - память ядра ОС, которая обслуживает процесс, например, таблица соотвествии виртуальных адресов физическим, буферы сокетов (именно сюда сначала попадают данные из внешнего источника), дескрипторы открытых файлов процессом, стек потока в ядре (нужен когда поток делает системный вызов)
2. Управляемая куча
