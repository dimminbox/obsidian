**Offset 8** — поле начинается на смещении 8 байт от начала объекта. Первые 8 байт — служебный заголовок (указатель на MT), поэтому поля начинаются с 8.
**Type: System.Guid** — тип поля, это Guid (16 байт).
**VT: 1** — value type (структура, лежит прямо в объекте, не ссылка).
**Attr: instance** — обычное поле экземпляра.
**Value: 00007f2cba903218** — для value-типа это **адрес, где лежат байты Guid** (внутри самого объекта: 903210 + 8 = 903218, сходится с offset 8).
**Name: k__BackingField** — это backing field авто-свойства. В C# `public Guid Key { get; set; }` компилятор превращает в скрытое поле `<Key>k__BackingField`.

Память по происхождению:
Rss = Anonymous + Pss_File_RSS + Shmem_RSS

Память по владению/изменяемости:
Rss = Shared_Clean + Shared_Dirty + Private_Clean + Private_Dirty

Private = Private_Clean + Private_Dirty
Dirty = Shared_Dirty + Private_Dirty

Pss = Private + (Shared / число процессов, делящих страницу)
