
Каждый объект в куче кроме данных хранит также ссылку на таблицу вспомогательных данных, которые требуется не всегда и поэтому эти данные вынесены в специальную, отдельную таблицу. 

В ней хранятся
 - данные для [[Monitor, Lock]]. Это очередь потоков, которые ожидают объект, номер потока, который владеет блокировкой и прочая информация.
 - хэш - код объекта
 - данные для работы с COM объектами
 - данные AppDomain
