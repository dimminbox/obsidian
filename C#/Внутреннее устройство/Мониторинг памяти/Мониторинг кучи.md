Снепшот кучи снимается с помощью команды dotnet-dump collect -p PID. Он создаёт снепшот - файл, который можно прочитать с помощью команды  dotnet-dump analyze dump.dmp. Выполнив эту команду мы попадём в командную строку утилиты, которая поддерживает очень много разных команд. 

###### dumpheap

dumpheap -stat -gen gen0 показывает объекты в указанном поколении. Возвращает статистику объектов в указанном поколении в формате: MIT(идетификатор типа объекта в рантайме из таблицы методов), Count (количество объектов), TotalSize (общий размер), Class Name (имя класса)

Можно наложить фильтр по типу, например,  
dumpheap -stat -gen gen0 -type ProductsRemains.Core.Models.Product

###### dumpobj 

dumpobj 7f2cba903210 - это сам объект в куче по адресу выдаст:

Name:        ProductsRemains.Core.Models.Product
MethodTable: 00007f898d6a67b0 //ссылка на MT
EEClass:     00007f898d6929c0 //сыслка на EFClass
Tracked Type: false //отслеживаемость объекта касается взаимодействия с COM и нативной памятью
Size:        32(0x20) bytes
File:        /app/ProductsRemains.Core.dll
Fields:
              MT    Field   Offset                 Type VT     Attr            Value Name
00007f8986450bd8  400001b        8          System.Guid  1 instance 00007f888594f6a8 k__BackingField

- Offset 8 - поле начинается на смещении 8 байт от начала объекта. Первые 8 байт -  служебный заголовок (указатель на MT), поэтому поля начинаются с 8.
  
- Type: System.Guid - тип поля, это Guid (16 байт).
- VT: 1 -  value type (структура, лежит прямо в объекте, не ссылка).
- Attr: instance - обычное поле экземпляра.
- Value: 00007f2cba903218 -  для value-типа это адрес, где лежат байты Guid (внутри самого объекта: 903210 + 8 = 903218, сходится с offset 8).
  
- Name: k__BackingField -  это backing field авто-свойства. 
  В C# код "public Guid Key { get; set; }" компилятор превращает в скрытое поле 
  
```csharp
private int <Id>k__BackingField;
public int get_Id() => <Id>k__BackingField;
public int set_Id(int v) => <Id>k__BackingField = v;
```
