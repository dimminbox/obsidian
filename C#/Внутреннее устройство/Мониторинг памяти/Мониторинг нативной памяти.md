##### smaps_rollup

Для того, чтобы получить агрегированную сводку о потреблении памяти можно использовать /proc/PID/smaps_rollup:

Rss:               95756 kB //Resident Set Size, Rss = Shared_Clean + Shared_Dirty + Private_Clean + Private_Dirty

Pss:               84799 kB //Proportional Set Size, тот же RSS но shared память учитвается не целиком а только той частью, которая используется этим процессом, по сути Shared/N процессов

Pss_Anon:          55652 kB //Proportional Set Size, Anonymous - пропорциональная Pss - часть анонимной памяти

Pss_File:           5711 kB //Proportional Set Size, File - пропорциональная Pss - часть памяти, приходящаяся на страницы, которые прочитаны из диска (библиотеки с диска, общие файлы)

Pss_Shmem:         23435 kB //Proportional Set Size, Shared Memory - пропорциональная часть разделяемой памяти из Pss

Shared_Clean:      16644 kB //память, которая используется в разных процессах и совпает с диском (обычно библиотеки)

Shared_Dirty:         28 kB //память, которая используется в разных процессах и НЕ совпает с диском

Private_Clean:        72 kB //память, которая используется только в этом процессе и совпадает с диском

Private_Dirty:     79012 kB //память, которая используется только в этом процессе и НЕ совпадает с диском

Referenced:        90072 kB //объём резидентной памяти, которая недавна была прочитана.

Anonymous:         55652 kB //объём памяти, выделеной без учёта файлового бекинга

LazyFree:              0 kB //память, которую приложение пометило как не использованную но ядро ОС её ещё не забрало

AnonHugePages:         0 kB //часть Anonymous, объем памяти, обслуживаемый через механизм ТНР(Transparent Huge Pages) когда ядро склевивает области памяти в большие страницы для уменьшения нагрузки на TLB. TLB - кеш в процессоре, который хранит соответствие виртуальной адресов и физических.

ShmemPmdMapped:        0 kB //аналог AnonHugePages только для shared memory

FilePmdMapped:         0 kB //объём памяти, которые склеены в huge pages и прочитаны с диска

Shared_Hugetlb:        0 kB //разделяемая память для huge pages, которые взяты из специального пула страниц

Private_Hugetlb:       0 kB //неразделяема память для huge pages, которые взяты из специального пула страниц

Swap:                  0 kB //объем памяти в swap

SwapPss:               0 kB //объём памяти, вытесненной в swap и посчитанной пропорционально, т.е. с учётом того что страницы могут быть использованы несколькими процессами

Locked:                0 kB //объём памяти, которую запрещено вытеснять (ни в swap ни выбрасывать)


Память по происхождению:
Rss = Anonymous + Pss_File_RSS + Shmem_RSS

Память по владению/изменяемости:
Rss = Shared_Clean + Shared_Dirty + Private_Clean + Private_Dirty

Private = Private_Clean + Private_Dirty
Dirty = Shared_Dirty + Private_Dirty

Pss = Private + (Shared / число процессов, делящих страницу)
