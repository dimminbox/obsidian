
Сначала Roslyn компилирует c# код в IL. JIT  (Just in time) компилирует IL(intermediate language) в машинный код, используя tiered compilation.

Вместо JIT компиляции можно вызвать AOT (Ahead of time) компиляцию и она сразу создаст бинарник с машинным кодом. Такие бинарники включает в себя все библиотеки, минимальный  runtime, обычно "весят" такие бинарники довольно много.

AOT компиляция бывает двух видов: 
 - ReadyToRun - это компромисс между JIT и AOT, скопилированный бинарник содержит и IL и машинный код. Запускаемся сразу в машинном коде, но по мере работы приложение JIT может перекомпилировать методы с использованием Tier1 чтобы они были более оптимизированными. В этом режиме работает рефлексия за счёт того, что в бинарнике сохранён IL.
 - Native AOT.  Результирующий бинарник не содержит вообще IL. Все методы скомпилированы с помощью Tier1 поэтому приложение получается изначально оптимизированным.  Рефлексия ограничена т.к. работает через методанные IL
   
После процесса компиляции получается Assembly - единица развёртывания кода представляет из себя скомпилированный файл .dll или exe

Кроме CLR приложение при компиляции использует CLS (Common Language Specification). Это набор ограничений и правил для написания кода, чтобы код, написанный на одном языке мог работать с кодом на другом, например, при создании nuget - пакета. Это могут быть следующие ограничения:
-  использовать только совместимые типы
-  имена методов не должны отличать только регистром, т.к. Vb.Net нечувствителен к нему)
- нельзя использовать указатели
- при перезагрузке оператора должен быть альтернативный метод
- все публичные Exception должны быть унаследованы от Exception

CTS (Common Type System) - система типов, которую наследуют все языки .Net
