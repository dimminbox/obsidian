
Именованный объект в памяти, который создаётся средствами ОС и нужен чтобы синхронизировать разные приложения. Ипользуя для решения проблем типа - не дать двум экземплярам приложения запуститься одновременно. Он дороже чем lock так как использует только средтва ОС в том время как lock с начала использует spinlock (крутит цикл).
