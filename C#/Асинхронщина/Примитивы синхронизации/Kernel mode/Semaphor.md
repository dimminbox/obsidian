
Это именованный объект в ядре. Каждый поток, который использует его при проверки доступа к ресурсу переключается в kernel mode (ядро ОС), который проверяет этот объект в ядре. Переход в kernel mode - это по сути переход управления от программы к ОС а для этого нужно где - то сохранить контекст выполнения программы а это влечёт за собой множества тактов процессора. Используется для синхронизации процессов.

#### SpinLock 
Это цикл, который мы крутим какое небольшое время а после завершения цикла идём смотреть не освободился ли ресурс.
