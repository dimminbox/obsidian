
Это именованный объект в ядре. Каждый поток, который использует его при проверки доступа к ресурсу переключается в kernel mode (ядро ОС), который проверяет этот объект в ядре. Используется для синхронизации процессов.

#### SpinLock 
Это цикл, который мы крутим какое небольшое время а после завершения цикла идём смотреть не освободился ли ресурс.
