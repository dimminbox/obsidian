Это примитив синхронизации, который работает на очередях. Например, первый поток захватил ресурс, второй поток тоже хочет прочитать ресурс, но не может т.к. он заблокирован. Когда первый поток отработал он вызывает Release вручную и это будет следующие на очереди поток на доступ к ресурсу.

Первый параметр - это количество соотвествующее количество потоков, которые могут читать его по - умолчанию. Второй параметр - максимальное количество потоков, которые могут читать семафор. 

Работает в рамках одного процесса но может синхронизировать доступ к данным в рамках разных потоков.
