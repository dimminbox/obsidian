Блокирует переменную на время изменения и таким образом решают проблему конкурентного доступа до переменной.

Гарантирует блокировку только одной переменной и поэтому не подходит для согласованного изменения сразу нескольких переменных, которое умеет делать lock.

Работает очень быстро потому что не работает в kernel mode, при чтении переменной блокирует доступ другим потокам к шине памяти по указанному адресу. Эта блокировка выполняется средствами CPU и поэтому это происходит быстро.

Interlocked читает значение переменной из памяти, не используя кеш CPU. Также гарантирует, что команды будут выполнены последовательно, т.е. ровно в том порядке в котором они записаны в коде.

По сути этот примитив надмножество над volatile.
