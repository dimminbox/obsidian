Task.WhenAll подходит для IO-bound (зависят от запросов к внешним системам) задач в то время как Paraller.Foreach подходят для задач связанных с CPU-bound (нагрузка на процессор) задач. В случае с task,whenall будут ПАРАЛЛЕЛЬНО сделаны запросы к внешним системам.  Это работает следующим обрзом:

1. .NET поток передаёт запрос ядру ОС и уходит обратнов  ThreadPool
2. Ядро формирует tcp пакет и отсылает его через сетевую карту
3. Когда ответ получен сетевая карта генерирует прерывание, ядро это прерывание обрабатывает
4. Ядро уведомляет .NET приложение через механизм IO Completion Port что запрос обработался.  IO Completion Port - это что - то типа очередей.
5. .NET берёт свободный поток из ThreadPool для обработки результата запроса

Paraller блокирует потоки на время выполнения. Если заблокировать все потоки, то это может привести к проблеме thread starvation.
