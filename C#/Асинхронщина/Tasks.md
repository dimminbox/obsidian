
Task - ссылочный тип и приводит к аллокациям в куче. ValueTask - значимый тип и находится на стеке. Он используется как результат выполнения метода когда внутри метода есть и синхронные и асинхронные операции и есть довольно большая вероятность (хотя бы 50%), что не будет выполнено асинхронных операций, т.е. он даёт пространство для манёвров и может возвразать как Task так и просто значение. Его нельзя выполнять параллельно потому что он может быть не Task а просто значением.

Thread.Sleep замораживает приложение, Task.Delay - нет, он запускает таску в отдельном потоке

Task.WaitAll - синхронный, Task.WhenAll - асинхронный.

Контекст синхронизации сообщает в каком потоке продолжить выполнение программы после await. 

`ConfigureAwait(false)` - не захватывает контекст синхронизации и не возвращается в предидущий поток после выполнения await. Если поставить configureawait(false) для UI приложения, то будет Exception.

async void не возвращает таску и поэтому вызывающий поток не ждёт её выполнения поэтому любой exception, возникающий внутри async метода крашит приложение. Исключение падание в SynchronizationContext и крашит приложение вместо того чтобы попасть в Task.

Чтобы превратить синхронный код в асинхронный можно использовать:

- Task.Run (() => {...} );
- Task.FromResult(result);
- TaskCompletionSource
