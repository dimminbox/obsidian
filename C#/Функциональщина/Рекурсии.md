В обычной рекурсии мы ждём результат выполнения метода чтобы выполнить какую - то операцию с ним. 

Пример с факториалом:

factorial(5) ← помни n=5, потом умножишь factorial(4) ← помни n=4, потом умножишь factorial(3) ← помни n=3, потом умножишь factorial(2) ← помни n=2, потом умножишь factorial(1) → вернул 1

То есть в обычной рекурсии мы должны помнить значения переменной после каждого шага, на которую нужно умножить значения факториала.

В хвостовой рекурсии обратного прохода нет и нет смысла хранить все значения результата чтобы двигаться обратно.  

FactorialTail(5, 1) FactorialTail(4, 5) FactorialTail(3, 20) FactorialTail(2, 60) FactorialTail(1, 120) FactorialTail(0, 120) → возвращает 120

Тоесть вместе с аргументом мы также передаёт аккумулятор который в итоге и будет результатом.
