
#### Record
Этот тип появился чтобы обеспечить иммутабельность без boilerplate кода. Раньше для этого использовался класс, в котором надо было делать иммутабельными поля, реализовывать Equals(object), GetHashCode() чтобы сравнивать объекты класса по значнию. По сути это класс с дополнительными возможностями.

Теперь с C# 9 появился типа record который умеет ряд преимуществ:
-  обеспечивает иммутабельность
-  возможность копирования объекта с изменением через with
- позволяет сранивать объекты по значениям, т.е. record будут равны если у них одинаковые свойства.
-  по - прежнему поддерживает наследование
-  поддерживает custom constructors
-  сравнивает объекты по значению
#### Tuples

Это просто контейнер, который хранит значения разных типов. Он нужен в ситуации когда класс избыточен.

`(int Code, string Message) GetResult()` 
`{` 
	`return (200, "OK");` 
`}` 
`var result = GetResult();` 
`Console.WriteLine(result.Code); // 200` 
`Console.WriteLine(result.Message);`

Его можно объявить заранее как alias, он потокобезопасный

#### ImmutableList

Находится в System.Collections.Immutable

Cписок,  который невозможно изменить, при добавлении нового элемента или удалении элемента по индексу создаётся новая коллекция. Это принцип иммутабельности, как со строками. Список потокобезопасный так как его никто не может изменить и мы всегда знаем из чего он состоит.
#### Frozen

Находится в System.Collections.Frozen

В отличие от ImmutableList вообще не имеет методов Add, Remove. Она быстрее чем все остальные коллекции так как он анализирует ключи, подирает хэш - функцию и строет оптимизированную таблицу в памяти ОДИН раз так как все элементы известны и меняться не будут. Любую коллекцию можно сделать frozen.
