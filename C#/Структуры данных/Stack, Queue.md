Stack - это структура данных по принципу LIFO т.е. первый добавленный будет извлечён последним. Используется для:
-  Redo/Undo операций
-  обход дерева в глубину [[Деревья (BFS, DFS)]]
-  стек вызова в программе

Queue - это структура данных по принципу FIFO, т.е. первый добавленный будет первым извлечённым. Используется для:
-  для брокеров
-  обход дерева в ширину [[Деревья (BFS, DFS)]]
-  очередь задач
