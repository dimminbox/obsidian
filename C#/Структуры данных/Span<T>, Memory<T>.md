
Структура, которая описывает участок памяти который может быть как на стеке на и в куче. По сути это указатель. 

При указании на кучу он не делает аллокации т.к. по сути это структура, описывающая память.

Его нельзя использовать в async операциях т.к. он является частью текущего стека вызова. При async операциях стек текущего вызова УНИЧТОЖАЕТСЯ.

Также он не может быть полем класса т.к. он раполагается исключетельно на стеке, который очищается по завершению выхода из метода в том время как объекты в куче продолжают существовать.
