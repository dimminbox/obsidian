
Scope - это контейнер, который создаётся для каждого HTTP запроса и уничтожается, когда запрос отработал.

В рамках scope можно получить через DI объект класса, удовлетворяющий условиям, которые были заранее зарегестированы при старте приложения.

Singleton - объект, который создаётся ровно один раз на все время жизни приложения.
Scope  - объект, который создаётся один раз на scope.
Transient - объект, который создаётся каждый раз когда заправшивается.
