
Scope - это контейнер, который создаётся для каждого HTTP запроса и уничтожается, когда запрос отработал. Он  создаётся через `IServiceProvider`/`IServiceScopeFactory` и регистрируется в `IServiceCollection`.

В рамках scope можно получить через DI объект класса, удовлетворяющий условиям, которые были заранее зарегестированы при старте приложения, т.е. определить lifetime объектов, которые будут определены для объектов. 

Они бывают следующий видов:

Singleton - объект, который создаётся ровно один раз на все время жизни приложения.
Scoped  - объект, который создаётся один раз на scope, например, в рамках одного http запроса.
Transient - объект, который создаётся каждый раз когда заправшивается.
