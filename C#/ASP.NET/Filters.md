
Filters - это специальные методы, которые выполняются только для API запросов в отличие от middlewares, которые выполняются для всех видов запросов, включая статические.

Фильтры выполняются до или после запроса. Например:
- Authorization Filter выполняется самым первым до всех остальных фильтров и проверяет можно ли идити запросу дальше
- Resource Filter выполняется в самую первую очередь ещё до того момента пока asp.net преобразует данные в модель через FromBody, FromQuery, FromRoute и т.д. 
  Главная задача - кеширование. То есть когда запрос пришёл  мы можем залезть в кэш и посмотреть есть ли валидные данные в кеше. 
  
  Также выполняется в самую последнюю очередь когда изменить уже ничего не нельзя в ответе и выполняет установку кеша.
- Action Filter содержит методы, которые выполняются до и после запроса. Нужен для того, чтобы выполнять какие - то действия перед и после выполнения метода.
- Exception Filter выполняется только в случае возникновения Exception.
- Result Filter. Метод OnResultExecuting выполняется после Ok(result), но до того как ответ будет записан в response для передачи клиенту. Это по сути последний шанс изменить ответ. 
  
  ResultFilter.OnResultExecuted выполняется после формирования ответа и после записи в response, на этом этапе мы уже не может изменить ответ, мы можем снять только метрики, в частности время затраченное на серилизацию ответа.
