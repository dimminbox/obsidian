Мидлвары - это специальные класс в ASP.Net, которые имеют доступ к HttpContext и могут передавать запрос по цепочке дальше к endpoint. На их базе обычно делают аутентификацию, логирование, обработку ошибок, телеметрию и т.д.

Они работают по принципу матрёшки, т.е. первая запускается, затем выполняет метод next() и тем самым запускает вторую. Когда вторая завершится запрос перейдёт к endpoint и после его завршения запрос опять пройдёт по мидлварам но только в обратном порядке пока не завершится самая первая.

app.Use - это использование миддлвары
app.Run - это терминальный endpoint

Миддлвары живут как синглтоны и поэтому любые scoped - зависимости нельзя передвать в конструкторе. В него можно передавать RequestDelegate - это делегат, т.е. специальный тип для функции с сигнатурой Task (HttpContext). 

RequestDelegate  - это делегат, который внутри себя содержит другой RequestDelegate другой миддлвары и т.д. пока не доберётся до делегата, который описывает конечный обработчик.

Также у мидлвар есть метод InvokeAsync(HttpContext context, что - то ещё) куда можно передавать scoped - зависимости из DI. Этот метод выполняется каждый раз при вызове мидлвары и поэтому может брать зависимости из DI контейнера.
