
Это подход, который появлился в Net 6 и который позволяет реализовывать контроллеры с использованием минимум кода, например, в Program.cs в отличие от классических контроллеров с использованием большого количества boilerplate кода.

Minimal API Controllers быстрее классических т.к. пропускают ряд операций при прохождении запроса а также имеют ряд ограничений:

-  нет класса, конструктора и соответсвнно DI - контейнера в конструкторе. Заивисимости инжектируются прямо в hadlers
-  нет фильтров [[Filters]] но есть EndpointFilter (аналог ActionFilter)
-  нет наследования контроллеров
