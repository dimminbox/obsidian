Это алгоритм, который называют иногда "метод половинного деления" для обхода сортированного массива при поиске элемента target. Состоит из следующих шагов:

- искомый массив делится на две части
- если серединный элемент middle массива - это тот который мы ищем, то возвращаем его
- если нет, то выбираем нужную половинку массива сравнивая middle c target. Если middle < target то двигаемся вправо (увеличивая left), если middle > target, то влево (увеличивая rigth)
-  устанавливаем индексы начального и конечного элемента в соответствии с этой найдённой половинкой, игнорируя серединный элемент ведь мы его уже проверили
- повторяем операцию деления массива пополам
-  останавливаем цикл когда left <= right, т.е. цикл выполняется только тогда, когда есть хотя бы единичный диапозон для поиска. 

Сложность алгоритма логорифм от n, т.к. область поиска элемента каждый раз уменьшая в 2 раза.
