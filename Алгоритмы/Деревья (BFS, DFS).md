
Эти алгоритмы обходят деревья в ширину (BFS) и в глубину (DFS) и имеют сложность O(n), т.е. очень быстрые.

Обход в ширину (BFS) обходит дерево по слоям, т.е. надо каким - то образом запоминать в структуру данных (часто это очередь) вершины деревьев на каждом слое. Т.е. по сути это цикл, который 
1.  Берёт корневую вершину, кладёт её в очередь.
2.  Берёт всех потомков всех вершин, которые есть в очереди, удаляя родительские вершины из очереди. Изначально там всего одна вершина - это корень.
3.  Далее опять проверяет потомков всех родительских верхин, удаляя родительские вершины из очереди и т.д.

Процесс заканчивается когда в очереди не остаётся вершин, т.к. каждый последущий слой перетирает каждый предыдущий в очереди.

Обход в глубину, который часто состоит в том, чтобы найти самый глубокий путь в дереве, обычно состоит в рекурсивном вызове функции, которая возвращает максимальную глубину ветки (в случае если есть дочерние элементы), вызывая рекурсивно саму себя для каждого дочернего элемента В самом низу дерева дочерних элементов нет и функция возвращает 1 если элемент существует и 0 если его нет,. Происходит выход из рекурсии и алгоритм возвращается к корню дерева, учитывая глубину веток.

```
public int MaxDepth(TreeNode root)  
{  
    int length = 0;  
    if (root != null)  
    {        length++;        int leftLength = 0;  
        int rightLength = 0;  
  
        if (root.left != null)  
        {            leftLength += MaxDepth(root.left);  
        }  
        if (root.right != null)  
        {            rightLength += MaxDepth(root.right);  
        }  
        length += Math.Max(leftLength, rightLength);  
    }  
    return length;  
}
```

Практически алгоритм применяется при решении следующих задач:
-  работа B-tree индексов БД
-  поиск элементов
- поиск кратчайшего пути в графе
- обход файловой системы по вложенности
- маршрутизация
