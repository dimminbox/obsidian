
Согласованное хэширвание - алгоритм распределния данных по узлам. 
Данные и серверы распределны на воображаемом кольце причём каждый сервер распределен там по несколько раз с помощью хэш функции. Для того, чтобы понять на какой сервере нам нужно хранить данные мы просто берём первый попавшийся сервер по часовой стрелке
