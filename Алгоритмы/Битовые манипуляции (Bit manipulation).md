
Это битовые операции которые позволяют без использования дополнительных дорогих структур решать простые задачи, например, поиск дупликатов.
Все они имеют сложность O(1) 

Виды битовых операций:
 -  XOR - операция которая будет давать 0 если её два раза применить к одному и тому же числу, т.е. если a xor a = 0 или b xor a xor a = b
 - проверка чётности. операция n & 1 просто проверяет последний бит, если 1 - то число нечётное
 - сдвиги n << k и n >> k сдвигают биты на указанное количество позиций, т.е. сдвиг на 1 бит влево увеличивает число в 2 раза, вправо - уменьшает число в 2 раза
 - n & (n-1) обнуляет первый попашиеся младший бит
 - битовые маски для хранения состояний через сдвиги влево и вправо
`int used = 0; used |= (1 << i); // пометить элемент i как использованный` 
`bool isUsed = (used & (1 << i)) != 0; // проверить, использован ли элемент i` 
`used &= ~(1 << i); // снять пометку с элемента i`

Применяются в: 
- для поиска количества единичных битов (popcount), сжатия данных, ML, построения битовых индекстов
- поиск уникального, непарного элемента
- проверить является ли число степенью двойки/четырёх (через n * n - 1 == 0)
- для компактного хранения уже пройденных элементов через битовые маски
