
Алгоритм исопльзуется для поиска слов по дереву, где вершинами являются буквы слов, т.е. у каждой буквы есть "дети" а также признак того, что буква последняя (IsEnd = true). Слова с одинаковым началом представлены в дереве одной общей веткой, например, car и card. Не умеет искать по середине или по концу слова.

Поиск по дереву идёт сверху вниз, имеет сложность O(n) где n - длина искомого слова. Сложность не зависит от размера словаря. Также может быть использован для поиска слов по префикам. Иногда используется совместно с [[Деревья (BFS, DFS)]] а также с [[Перебор с откатом (Backtracking)]] для движения по сетке и по строке с одновременным движением по trie для ускорения перебора (если мы ищем сразу несколько слов)

Используется для:
 - полнотекстовый поиск по префиксву
 - автодополнение
