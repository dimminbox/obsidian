
Паттерн позволяет обходить структуру данных (дерево, массив и пр) не за n! шагов а за 2 в степени n шагов выражая каждый последующий элемент через предыдущие. По сути это рекурсия, но тут есть очень важное отличие - это использование кеша для подсчёта значения для n элемента. Т.к. мы вынуждены считать значение функции для n - го элемента несколько раз и каждый раз оно одно и то же, то почему бы его просто не закешировать, в этом случае сложность падает до O(n) операций. Это и есть основная идея этого алгоритма. 

Классический пример - числа Фибаначчи, где каждое следующие число - это сумма двух предыдущих.

Например, следующий код - это решение задачи с лестницей. Нам необходимо посчитать количество способов взобраться на n ступеньку если мы можем либо наступать на каждую ступеньку либо перепрыгивать одну, т.е. у нас шаг либо +1 либо +2.

 
private Dictionary<int, int> cache = new();  

public int ClimbStairs(int n)  
{        if (cache.ContainsKey(n))  
	{            return cache[n];  
	}  
	if (n <= 2)  
	{            return n;  
	}  
	cache[n] = ClimbStairs(n - 1) + ClimbStairs(n - 2);  
	return cache[n];  
}`

Также этот паттерн может быть применён не к одномерному массиву точек но также и к многомерной матрице (с одновременно меняющимися двумя параметрами, которые в сумме дают значение). В этом случе это будет уже 2DP.
