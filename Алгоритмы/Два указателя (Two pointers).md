Применяется, когда нужно совершить обход массива где есть некоторая структура (сортировка) или задача разделения элементов на группы (например, нули/не нули).

Алгоритм использует два указателя которые перемещаются по массиву, модифицируя его или выполняя поиск необходимых элементов для выполнения заданного условия. Он имеет O(n) сложность, то есть все действия совершаются в один прогон.

Указатели могут двигаться навстречу друг другу, выполняя поиск пар по заданному условию. Также они могут двигаться в одну сторону для с разной скоростью для модицикации массива на месте.

Основной проблемой использования этого алгоритма - это необходимость следить, чтобы указатели не пересекались и не выходили за пределы массива.

Классическими задачами на применение этого алгоритма являются - нахождение пары элементов, нахождение палиндрома (строка, которая слева на права читается как справа налево).

Используется для следующих практических задач:
 -  слияние отсортированных массивов
 -  обработка данных на месте без создания нового массива
 -  дедупликация данных когда данные уже отсортированы 
 -  валидация данных
