Этот алгоритм перебора предназначен для составления всех возможных комбинаций из набора данных. Имеет сложность n!.

Основная идея этого алгоритма - это рекурсивный перебор всех элементов набора данных с использованием цикла в каждой итерации. Для работы алгоритма должна быть определена функция, которая бы вызывала саму себя если комбинация элементов не полная и завершалась если мы собрали полную комбинацию.

Замысел этой функции - это подготовить комбинацию и когда варианыт исчерпаны сделать шаг назад.

Например, возьмём массив из 3 элементов. Необходимо составить все возможные комбинации из них. Запустим рекурсивную функцию, которая будет обходить все элементы массива и для каждого элемента будет пытаться создать комбинацию. 

Когда мы встретили элемент, которого ещё нет в нашей комбинации, то добавляем его в комбинацию и запускаем рекурсивно ту же самую функцию второй раз (второй слой), которая будет добавлять другой элемент массива в комбинацию и внутри себя будет запускать третий слой. 
Когда этот третий слой добавит третий элемент массива, то он запустит опять функцию в четвёртый раз. На этот раз эта четвёртая функция завершится (т.к. комбинация собрана) и после её завершения мы удаляем добавленный элемент массива и выходим из третьей функции. Мы попадаем во вторую функцию, которая в свою очередь ранее добавила второй элемент массива, подобрала для него комбинацию через третий слой и теперь настало время удалить второй элемент массива и переместится к третьему элементу. 

Для третьего элемента мы делаем то же самое, поставив его на второе место а потом запуская рекурсивно функцию собираем комбинацию.

Собрав комбинацию, мы выходим из цикла тем самым завершая вторую функцию и возвращаясь в первую, где мы уже подготовили все комбинации и теперь настало время удалить первый элемент из первой позиции и переместится на вторую позицию в первой функции. Тем самым первый элемент в новой комбинации у нас теперь будет 2 а не 1 как раньше.

public void backtrack(IList<IList<int>> result, IList<int> current, int[] nums)  
{
