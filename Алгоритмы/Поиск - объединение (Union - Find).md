
Алгоритм предназначен для того, чтобы находить общие связи между элементами, которые друг с другом связаны в хаотичном порядке. Он представляет из себя процесс сборки разнородных деревьев в общий лес объединения корней корней деревьев через общие элементы.

Алгоритм имеет сложность O(N), но с оптимизацией будет примерно O(1) т.к. для каждого элемента мы будем знать его корневой элемент.

Разберём пример. Дан массив ребёр между вершинами [1, 2], [2, 3], [3, 4], [1, 4], [1, 5], нужно найти какое ребро является лишним чтобы избавится от цикла. Алгоритм работает следующим образом:
- считаем, что все вершины атомарны и находятся в разных деревьях, т.е. для каждой вершины она же является и корнем дерева, т.е.у элемента 1 корень - 1
- берём элемент 1 и ставим для неё корневым элементом 2
- берём элемент 2 и видим, что 2 это корень для 1 поэтому для 1 ставим корень 3
- берём элемент 3, он является корнем для 1 поэтому ставим 1 корень 4
- берём элемент 1 и видим, что у нас уже для него корневым является 4, т.е. уже существует связь между 1 и 4 посредством каким то элементов. Но мы тут хотим проложить прямую связь между 1 и 4 и поэтому делаем цикл.

То есть алгорит базируется на двух методах:
- Find, который ищет корневой элемент для текущего элемента. Этот метод может быть с оптимизацией, т.е. для каждого элемента в некоторой структуре будет хранится корневой элемент.
- Union - это метод, который устанавливает для корня текущего элемента новый корень, т.е. тем самым связывает деревья воедино.

Алгоритм может быть применён для таких прикладных задачах как:
 - в социльных сетях найти друзей, друзей
 - рекомендательные алгоритмы
 - проверка связности сети
