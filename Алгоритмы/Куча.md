
Это структура данных, которая позволяет найти k-ый по величине элемент из массива не прибегая к сортировке. Она представляет из себя дерево, где в корне находится либо самый маленький элемент либо самый большой (это зависит от настройки кучи). При нахождении k - го элемента по величине нам нужно всего лишь сформировать кучу, которая содержала бы k  - элементов, но в начале её был самый маленький элемент из этих k элементов. По сути оно похоже на сито, которое фильтрует элементы и позволяет оставить только k элементов.

При записи в кучу мы выполняем следующие действия:
 -  Помещаем элемент в свободное место в дереве
 - Сравниваем этот элемент с его родителем, если он меньше, то меняем их местами
   
  Структтура имеет следующие сложности: 
 -  при добавлении - O(log2N) т.к. мы используем дерево и поэтому для прохождения его получается логарифм.
 -  при чтении O(1)
 -  при удалении O (log2N)
   
Применение для "k-й по величине элемент": 
- Держим min-heap ограниченного размера k. 
-  Добавляем элементы по одному; 
- Если размер кучи превышает k — удаляем минимум ("просеиваем"). 
  
В итоге куча содержит k наибольших элементов массива, а минимум среди них (верхушка кучи) — это и есть искомый k-й по величине элемент.

В C# существует встроенный тип [[Queue (Очередь)#PriorityQueue]].

Применяется в следующих прикладных задачах:
- Балансировка нагрузки, где нужно отправлять задачу на наименее загруженный сервер
- Приоритетные очереди задач где необходимо выполнять сначала только самые критичные.
