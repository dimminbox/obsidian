- HTTP2  использует бинарный формат, http1 текстовый
- http2 использует сжатие заголовков, в http1 они передаются в каждом запросе текстом что расточительно
- в http2 несколько запросов может идти параллельно в одном соединении, в предидующей версии они идут последовательно
- в http2 сервер может отдавать клиенту css и js вместе с html даже если он этого не просил
- клиент может выставить приоритеты относительно тех ресурсов, которые он хочет получать сначала
- одно tcp соединение
