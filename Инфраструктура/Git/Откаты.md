#### git reset
Откатывает коммиты до указанного, например, git reset --soft HEAD~1 откаывает последний коммит. У команды есть флаги
- --soft - откатывает так, чтобы изменения были в индексе готовыми для коммита
- --mix - откатывает так, чтобы изменения были просто в файлах
- --hard - откатывает так чтобы изменения пропали совсем.

Вместо HEAD~1 может быть указан hash любого коммита.

#### git revert
Иногда бывают ситуации когда нужно просто убрать какой - то коммит. Для этого можно использовать git rebase  --onto, которая перестроит хэши коммитов, которые идёт после удалённого. Далее нужно будет толкнуть всё это на сервер через 
git push --force-with-lease --force-if-includes. Но это чревато проблемами т.к. ту же самую ветку может использовать другой человек и вносить туда свои изменения.

Откатить вручную можно без перезаписывания истории через:
git revert hash где hash - это коммит, который нужно откатить.
git push

Он создаёт отменяющий коммит с сообщением "Revert ..."

Откатить изменения в файле можно и через восстановление состояния файла из коммита

git restore --source=hash -- filename 
где source - это может быть hash коммита откуда взять корректный файл
filename - сам файл

Если нужно откатить коммит уже влитый через merge request обычный git revert не поможет т.к. он не может определить какого родителя коммита исопльзовать потому что их два. В качестве родителя мы можем указать ветку куда вливали и git revert откатит коммит в ней через команду git revert -m 1 M.

### Поиск удалённых объектов
#### ORIG_HEAD

Это объект хранит hash предпоследнего коммита (перед операциями merge, rebase reset, pull). Можно вернуться на предидущий коммит в экстренном случае через: git reset --hard ORIG_HEAD. 
#### git reflog
Это своего рода локальная история изменения или транзакций которая хранит множество измнеений, записи в ней истекают раз в 90 дней. Команда git reflog показывает эту историю. 
Далее найдя нужный коммит можн, например, создать ветку, которая начинается с него командой git branch rescue HEAD@{4} или вообще сбросить ветку до этого коммита git reset --hard HEAD@{4}.
#### git fsck

Бывает ситуации когда коммит теряется, т.к. на него больше никто не ссылкается или нужно найти удалённый stash. Для этого можно воспользоваться командой git fsck --lost-found. Она находит коммит путём обхода всех живых веток и коммитов, сверяет их с в .git/objects и затем выдаёт список недостижимых.

Восстановить коммиты можно следующими командами:
git show hash - просмотр коммита
git branch rescue hash, где hash - хэш коммита, создаёт ветку с указанного коммита
git stash apply hash, где hash - хэш stash - применяет stash к рабочей папке
