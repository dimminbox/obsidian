
###### git cat-file
Показывает содержимое объекта 

Например, git cat-file -p 2cfae6d64b7910257e5169bc6dde3ffb49d6245f показывает
Console.Write('Hello!');

Команда git cat-file -t 2cfae6d64b7910257e5169bc6dde3ffb49d6245f показывает тип объекта (blob, tree, tag, commit)

##### git rev-parse
Позволяет получить хэш любого объекта, указав его в специальном формате:
- git rev-parse HEAD                 # коммит
- git rev-parse HEAD~N # на N коммитов назад
- git rev-parse HEAD^N # выбирает N родителя (у merge коммита много родителей)
- git rev-parse HEAD^{tree, commit} # берёт объект HEAD и приводит его к типу tree, commit или любому другому, который указан.
- git rev-parse HEAD^n~m  # делаем m шагов назад у n родителя 
- git rev-parse HEAD^{tree}          # корневой tree
- git rev-parse HEAD:main.cs         # blob файла в этом коммите
- git rev-parse HEAD:test            # tree вложенной папки
- git rev-parse v1                   # объект-тег
- git rev-parse c1c3                 # короткий хэш → полный

Команда git rev-list --objects --all получает все хэши достижимых объектов.

##### git- log

Нужна чтобы посмотреть историю перемещений локально, которая берётся из reflog (git reflog),кроме этого показывает историю, перемещаясь по графу коммитов.

git reflog

81a29a9 (HEAD -> dev, tag: v1, master) HEAD@{0}: checkout: moving from master to dev
81a29a9 (HEAD -> dev, tag: v1, master) HEAD@{1}: commit (initial): init


Например, git log @{-1} возвращает лог ветки, на которой  были до текущей, @{-2} - на которой были до предидующей. НАпример, предыдующий шаг:

commit 81a29a92176be2a7f68e731d3bb9f4b180a42192 (HEAD -> dev, tag: v1, master)
Author: loginov.dn <loginovdn.it@relef.ru>
Date:   Tue Oct 20 22:13:46 2026 +0300
init

Команды, которые используют @{u} обращаются к локальной копии upstream ветки с сервера. 
Например, git log @{u}..HEAD показывает коммиты, которые есть локально и нет на сервере
git log HEAD..@{u} - коммиты, которых нет локально но нет на сервере
