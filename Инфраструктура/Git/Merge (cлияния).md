#### git merge 

Команда которая вливает коммиты одной ветки в другую. Она имеет несколько режимов работы:

fast-forward(--ff) используется только если одна ветка отстала от другой на несколько коммитов. В этом случае коммиты просто переходят в нужную ветку

commit(--no-ff) используется если ветки разошлись, создаётся объединяющий коммит, который содержит изменения при расхождении

squash (--squash) один коммит на весь merge. при этом все коммиты в рамках mr объединяются, история коммитов в назначенную ветку не попадает а git не считает ветку влитой.
