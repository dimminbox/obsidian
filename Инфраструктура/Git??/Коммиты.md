#### git add/restore
Иногда бывает, что изменений слишком много и нужно закомитить изменения в файле по частям. Для этого нужна команда git add - p которая предлагает варианты как закомитить, можно выбрать для коммита только конкретные изменения.

git restore -p сбрасывает изменения из индекса, затирает локальные изменения

#### git commit

git commit -v добавляет в редактор для сообщения всю информацию, которая коммитится.
git commit --amend добавляет в последний коммит новые изменения в индексе, добавленные через git add. Используется, когда закоммитили не все изменения но только в случае если их не отправили на сервер.
