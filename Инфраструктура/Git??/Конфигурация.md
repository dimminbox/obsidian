Все настройки ставятся командой git config --global или через файл ~/.gitconfig. Можем задать настройки для репозиториев, расположенных в указанной папке:
[includeIf "gitdir:~/work/"] 
	path = ~/.gitconfig-work

А в файле ~/.gitconfig-work указать рабочие данные: имя, почту

Иногда полезно использовать алиасы команд вместо того чтобы каждый раз набирать команду со всеми ключами. Например, 

git config --global alias.lg "log --oneline --graph --decorate --all"
задаёт алиас git lg для команды log --oneline --graph --decorate --all
В файле это выглядит следующим образом:
[alias] 
	lg = log --oneline --graph --decorate --all
