
По умолчанию используется BM-25 для рассчёта score. Но также можно использовать и другие способы для подсчёта score. 

{
  "query": {
    "function_score": {
      "query": { "match": { "title": "тормозные колодки" } },
      "functions": [
        {
          "field_value_factor": {
            "field": "popularity", // буквально берём значения поля
            "modifier": "log1p"
          }
        }
      ],
      "score_mode": "sum", // как объединяем значения функция
      "boost_mode": "multiply" // как объединяем итоговое значения функций с результатом BM-25
    }
  }
}

Существуют режимы изменения score от Bm-25:
- multiply (BM25 * результат из function_score). А данном случае мы умножаем score на log1p чтобы сгладить значения популярности
- summ - суммирует значение bm-25 c результатами функции
- replace - заменяет bm-25 результат тем, что посчитала функция

Кроме replace режима существует также другой способ самис считать score на основе результата, посчитанного BM-25 алгоритмом. Это script_score, он используется для подсчёта релевантности, в новых версиях используется painless, раньше использовался groovy, который убрали по по причинам безопасности исходя из того что он - полноценный java - подобный язык общего назначения и используя его можно было получить доступ не только к ES но и, к примеру, к файловой системе. По сути это способ написать небольшой алгоритм для итогового score. 

Если мы обращаемся из скрипта к полю документа ,который имеет тип text, то мы задействует структуру fileddata а это очень дорого. 

Т.к. выполнение скрипта на документах довольно нагруженный процесс, то для облегчения работы ES применяют оператор rescore. Идея такова, что script_score применяется только к определённой части документов, например, к определённой части (window_size). Изначально документы ранжируются по score, посчитанному через BM-25 для всех документов. Если script_score может в корне поменять score, то rescore может привести к ситуации, когда релевантные документы не попадут в первые window_size документов.
