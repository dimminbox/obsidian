
##### Анализаторы

За анализ текста в ES отвечают анализаторы, которые выполняются функции филтрации текста перед индексацией, разбиением текста на токены, работа с токенами (стемминг, удаление стоп - слов)

Когда ES принимает текстовое поле в документе, он должен сначала вычистить из него ненужные/мусорные символы, например, HTML - вёрстку. За это отвечает специальные фильтры, которые настриваются при задании схемы для индекса и являются частью анализатора.
Кроме этого можно настроить маппинг отдельных символов, например, заменить букву "ё" на "е" а также применить специальные паттерны для поиска и замены, убирая нежелательные фразы.

#### Токенизаторы

Далее начинается процесс токенизации, т.к. ES не хранит слова целиком, он хранит отдельные токены. Помимо самих токенов ES так же хранит позиции токенов а также начальную и конечную позицию оригинального слова. Последнее может быть использовано чтобы выделить фрагмент текста, когда, например, оригинальные слова, которые соотвественовали параметрам поиска выделяются html тегами.

Токенизаторы тоже бывают разные. Они по - разному разбиваются слова на токены:
- Standard Tokenizer разбивает слова по пробелам и знакам препинания.
- n-gram токенизатор разбивает слова с помощью скользящего окна на все возможные подстроки разной длины. Например, слово "колодки" с n-gram(3-4) даст токены типа "кол", "коло", "оло", "олод". Минимальный и максимальный размеры окна можно настраивать.

##### Фильтры токенов

Выполняют сразу нескольо функций:
 -  приводят слово к нижнему регистру, убирает пробелы с начала и в конце строки
 -  провдят токен к основе слова (стемминг), т.е. по сути выдляют смысловую часть слова, убирая окончания. Стемминг бывает двух выидов - словарный, алгоритмический. Словарный основан на сопостовлении слова со специальным словарём, который должне содержать огромное количество слов. Такие словари есть - это hunspell словари. Алгоритмический же просто пытается найти сонову слова на основе алгоритмов и как правило он менее точный чем словарный метод
 - добавляет синонимы слова, которые могут охватывать сразу несколько токенов 
 - добавляет токены для автокомплита
 - удаляет токен, если он находится в списке стоп - слов, удаляет токены короче определённого числа символов, удаляет неуникальные токены
   
Для обеспечения быстрой индексации используется bulk индексация, т.е. индексируется сразу пачка документов вместо одного.
