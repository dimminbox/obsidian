Для того, чтобы отсечь всякий хлам делается запрос 

{
  "query": {
    "bool": {
      "filter": [{
        "match": {
          "SEARCH.FILTER": { "query": "ручка", "analyzer": "FILTER_ANALYZER", "minimum_should_match": 1 //коичество слов из запроса, которые должны совпасть с полем.
          }
        }
      }]
    }
  },
  "size": 0
}
Где SEARCH.FILTER - это по сути краткая выжимка информации о товаре без штрихкода, артикула. Только самое важное.

Если фильтр возвратил минимум один товар, то такие товары точно есть и это условие будет добавлено в [[5. Финальный запрос]] как отдельное условие в filter, то есть это будет работать как сито.
