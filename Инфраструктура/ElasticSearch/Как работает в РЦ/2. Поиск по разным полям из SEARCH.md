

После коррекции мы должны узнать а не является ли наш терм названием раздела/бренда/серии, для этого выполняем следующий запрос с агрегацией по полю SECTIONS_ID.42.SECTION_ID (для раздела)

Нужно, чтобы следующими запросами сократить область поиска.

{
  "query": {
    "bool": {

        "dis_max": { //берём лучший вариант совпадения, по факту здесь бесполезно так как вариант запроса только 1

          "queries": [

                    "query": { //выбираем только те доки, у которых в названии есть ручка
                      "match": {

                            "lang": "painless",

Скрипт оценивает насколько хорошо произошло совпадение и в зависимости от этого накидывает баллы за score.
-  если иделаьное совпадение, то +factor
- если один токен существует, то factor делим на количество токенов
- в поле больше нет других токенов +factor

Здесь выполняется поиск по nested - полю SEARCH.SECTIONS, однако те же самы запросы должны выполняться для следующий полей: SEARCH.SYNONYMS (синонимы), SEARCH.TM (торговая марка), SEARCH.TM.FOR_RULER (серия)., SEARCH.PRODUCT.FOR_FILTER (слова для фильтра)
