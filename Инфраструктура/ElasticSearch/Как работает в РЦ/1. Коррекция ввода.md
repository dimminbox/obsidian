
Сначала идёт запрос к подсказкам через запрос

{
	  "query": {
		"match": {
		  "SEARCH.SUGGEST": {
			"query": "ручкавыаыва",
			"analyzer": "SUGGEST_ANALYZER"
		  }
		}
	  },
	  "suggest": {
		"text": "ручкп",
		"correction": {
		  "term": {
			"field": "SEARCH.SUGGEST",
			"analyzer": "SUGGEST_ANALYZER",
			"suggest_mode": "always",
			"max_edits": 1,
			"size": 1
		  }
		}
	  },
	  "size": 0
	}
	
SEARCH SUGGEST - это поле SEARCH (склеивает артикул, код и прочие данные) + DETAIL_TEXT
То есть выясняется есть ли товары вообще с таким словом и если нет, то проверяем не опечатались ли (через suggestion). Тем самым мы проверяем ввод.
Используется сложный анализатор:
	 {
		 "filter": [
			"trim",
			"lowercase",
			"WORD_PUNCTUATION",
			"NUMBER_DELIMITER",
			"NAME_SYNONYMS_FILTER",
			"SIZE_DELIMITER",
			"SEARCH_SUGGEST_DELIMITER_FILTER",
			"trim",
			"lowercase",
			"unique"
		],
		"char_filter": [
			"UNITS_DELIMITER",
			"UNITS_DELIMITER_END",
			"PUNCTUATION_CLEAR_BEFORE",
			"PUNCTUATION_CLEAR_AFTER",
			"LETTER_E"
		],
		"type": "custom",
		"tokenizer": "whitespace"
	}

В самом начале идёт выяснение, является ли поисковое слово разделом, торговой маркой, брендом или ещё чем - то определённым. Для этого существуют поля: SEARCH.SECTIONS, SEARCH.TM.FOR_RULES и др.
