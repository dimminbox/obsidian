
Помимо стандартных типов данных типа numeric, boolean ES содержит два типа данных, которые используются для хранения текста:

- text (для полнотекстового поиска), когда значение разбивается на токены. Используется, например, для названий, краткого описания товаров.
- keyword - для точного значения, сверяется целиком при поиске, не токенизируется, не разбивается на части. Используется, например, для артиклей товаров.

ES позволяет хранить одно и тоже поле в двух разных типах - text и keyword

Кроме этого часто используется тип nested. По сути - это вложенный список объектов, которые могут состоять из полей разных типов а также из других объектов, таким образом связь между свойствами не теряется, в то время когда object теряет связь между объектами.
Движок ES Lucene ипользует плоскую структуру и поэтому для каждого элемента из вложенных полей создаётся отдедельный дочерний документ, который физически расположен перед родительским поэтому связь между ними находится быстро. Поиск идёт по дочерним элементам, но возвращается родительский.

Помимо этих типов ES поддерживает типы - boolean, object,date.
