
ElasticSearch - поисковый движок (написан на движке Lucene), который основан на идее инвертированного индекса. Т.е. грубо говоря это работает как алфавитный указатель в книге. Любому слову соответвует массив документов где он встречается примерно так же как термину из книги соотвествует номер страницы, где этот термин описан. 

ES оперирует некоторыми терминами:
-  postings list - список номеров документов для конкретного слова
-  term dictionary - тот самый "алфавитный" указатель, т.е. отсортированный список всех уникальных слов.
-  term frequency - показатель, как часто слово встречается в документе

Всё остальное - сортировка, ранжировование результатов - это просто дополнительные функции, которые используются поверх этой основной идее.

При добавлении документа в индекс для каждого поля документа необходимо установить [[Типы данных]]]. Если для поля используется тип "text", то в работу включается анализаторы.

ES хранит на диске следующие данные:
-  _source - это сами документы_
-  doc_values - по сути это таблица из колоночной БД, которая хранит остсортированные значения по полям. По - умолчанию включено для всех полей, но если поле не используется в сортировке, агрегациях, фильтрации, то можно отключить doc_values в _mappings_
-  norms ранее хранился на диске, сейчас в heap, представляет из собой закодированное значения для поля документа, которое в дальнейшем может участвовать в ранижировании документа.

Если ES не указать типы полей, то он сам пытается угадать типы полей по первому документу (dynamic mapping) поэтому лучше использовать explicit mapping.

Анализатор  ([[Индексация документов ]]) - специальный механизм, который вычищает ненужные символы из строки, разбивает её на токены, убирает окончания (стемминг) и сохранеет её в индекс.
