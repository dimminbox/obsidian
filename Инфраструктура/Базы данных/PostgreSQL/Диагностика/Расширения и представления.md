pg_stat_statements хранит статистику по всем выполненным запросам. Статистика включает в себя: количество раз, которое запрос вызывался, среднее время, сколько буфером прочитал из диска и из кеша.

pg_locks хранит информация о [[Блокировки]]

pg_stat_activity хранит информация об активности, т.е. какие запросы сейчас выполняются и что делают.  Содержит поля:
- pid - пид процесса
- state - состояние
- wait_event_type - категория ожидания. lock - ждёт блокировку, LWLock - ждёт легковесную postgres блокировку, например, доступ к shared_buffers, io - дисковая операция, client - ждёт клиента, timeout - таймаут, например, ждёт autovacuum
- wait_event
- query


pg_stat_user_tables - это информация о таблицах, сколько seq scan, index scan, когда был последний autovacuum и т.д.

pg_stat_database - статистика по бд: количество commit/rollback и количество deadloacks.

pg_stat_replication - информация по репликам

pg_statio_user_tables - информация по io операциям для каждой пользовательской таблицы, а именно, количество страниц прочитано из диска, сколько из shared_buffers. Можно для каждой таблицы посчитать cache ratio который будет описывать какая доля страниц грузится из памяти, чем больше, тем лучше. Хорошим считается показатель от 99% для мелких транзакций.
