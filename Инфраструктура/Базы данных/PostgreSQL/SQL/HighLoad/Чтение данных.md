
При использовании OFFSET мы вынуждены читать предыдущие строки чтобы добраться до нужной поэтому чем больше OFFSET тем дольше будет выполняться запрос. Более того, при вставке/удалении страницы между существующими страницами OFFSET либо не учтёт данные либо выдаст дубликат.

По этим причинам лучше пользоваться keyset pagination т.е. использовать условие типа ID > number order by Id desc limit N где number - это либо 0 либо номер последней прочитанной записи. Но этот подход работает быстро только если есть индекс по полю по которому идёт сортировка. При keyset нельзя перейти на произольную страницу а при OFFSET можно.
