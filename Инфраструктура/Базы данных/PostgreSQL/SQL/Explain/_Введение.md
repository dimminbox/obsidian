
Exmlain это команда, которая предоставляет информации от планировщика запроса  о том как внутри запрос будет выполняться.

EXPLAIN имеет разные аргументы (ANALYZE, BUFFERS)

Сам план запроса представляет из себя список строк, например:

Gather  (cost=1000.00..275575.02 rows=54106 width=431) (actual time=3.795..272.702 rows=52977.00 loops=1)
  Workers Planned: 2
  Workers Launched: 2
  Buffers: shared hit=3461 read=238166
  ->  Parallel Seq Scan on shipment  (cost=0.00..269164.42 rows=22544 width=431) (actual time=5.450..231.838 rows=17659.00 loops=3)
        Filter: (contractor = '6c1c196e-bdeb-11e2-82b6-e0cb4eb4652b'::uuid)
        Rows Removed by Filter: 1744711
        Buffers: shared hit=3461 read=238166
Planning Time: 0.297 ms
JIT:
  Functions: 6
  Options: Inlining false, Optimization false, Expressions true, Deforming true
  Timing: Generation 0.955 ms (Deform 0.259 ms), Inlining 0.000 ms, Optimization 1.863 ms, Emission 11.377 ms, Total 14.195 ms
Execution Time: 275.061 ms

Читать его нужно снизу вверх:
1. Планировщик предположил, что запрос возвратит нам 22544 строк, но по факту вернулось 17659, также фактически изменилось время
2. shared:  hit - это чтение количества страниц из shared_buffers, read - из диска
3. тут запустилось 2 дополнтильных воркера и каждый прочитал по 17659 строк, в итоге было прочитано 54106
4. width - средний размер в байтах одной строки
5. cost - стоимость запроса, которая зависет от количества прочитанных страницу, количества обработанных строк и весовых коэффициентов
6. реальное время выполения запроса - 275,57502 мс
