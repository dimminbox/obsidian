- Seq Scan - полный перебор всех страниц таблицы
  
- Index Scan - идёт в индекс, получает TID, читает строки, находящиеся на разных страницах
  
- Index Only Scan - когда вся информация уже есть в индексе, на диск не ходит (когда все страницы без мёртвых данных в соответсвии с visibility map)

- Bitmap Heap Scan - используется когда есть много страниц для чтения, но не слишком много чтобы использовать seq scan. 
  Через индекс получает TID строк, строит битовую карту для найденных страниц. Она представляет из себя последовательность бит 1010100011, где позиция бита =1 , это номер страницы которую точно нужно прочитать. Затем читает их последовательно, что гораздо быстрее само по себе.
