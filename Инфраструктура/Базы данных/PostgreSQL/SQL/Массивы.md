Postgres поддерживает хранение массивов, тип поля колонки должен быть int[], int[] и т.д.

Для работы с ними существует следующие операторы:
- SELECT ARRAY[1, 2, 3]; SELECT '{one,two,three}'::text[]; - это создание массива
- WHERE ID = ANY(ARRAY[1,2,3]) это эквивалентно IN(1,2,3)
- WHERE sum < ALL(ARRAY[10,20]) это эквивалентно sum < 10 AND sum  < 20
- UNNEST(ARRAY[1,2,3]) разворачивает массив в строки
