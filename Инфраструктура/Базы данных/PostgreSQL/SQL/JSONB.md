Операторы для работы с JSON:

- `->` — получить элемент как JSONB: `data -> 'status'` возвратит "paid"
- `->>` — получить элемент как текст: `data ->> 'status'` → ` возвратит paid
- `@>` — содержит ли JSON другой JSON: `data @> '{"status": "paid"}'` - аналог операции сравнения в WHERE, может использовать GIN индексы
- `?` — есть ли ключ: `data ? 'status'`
- `jsonb_set` — изменить значение: `jsonb_set(data, '{status}', '"done"'), аналог операции присваивания только для JSON`
