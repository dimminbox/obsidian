EXTRACT - извлекает нужные данные из даты, например:

EXTRACT(period FROM AGE(start_date, end_date)) где период может быть - DAY, MONTH, YEAR, EPOCH (секунды мс с 1970 года), DOY (день года)

AGE(to, from) - разница между двумя датами возвращает значения типа интервал "годы-месяцы дни часы:минуты:секунды""

date_trunk(field, date) - обрезает дату используя точность field (day, month, year, sec and etc.)
То есть при передаче month получим первые числа месяцев

generate_series(start_date, end_date, period) - генерирует серии из диапозона дат, которые различаются периодом
