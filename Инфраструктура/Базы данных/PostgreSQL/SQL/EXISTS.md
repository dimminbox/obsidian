
Это по сути оператор - замена IN только более облегчённый, т.е. он не проверяет все строки а останавливается если нашлась первая строка. 

SELECT Name FROM Customers c
WHERE EXISTS (
    SELECT 1 FROM Orders o 
    WHERE o.CustomerId = c.Id AND o.Amount > 1000
);

Он возвращает true если подзапрос хоть что - то возвратил, в данном случае он возвратит 1 если существует заказ пользователя больше 1000
