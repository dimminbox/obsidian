
Специальный тип JOIN где внутри него можно обращаться к столбцам предыдущей таблицы.  
Бывает полезно в ситуациях когда запрос соединенят внешнюю и внутреннюю таблицу и внутреннюю таблицу мы можем не читать целиком, если нам необходимо взять оттуда несколько записей, например, для каждого КА вывести последние 3 отгрузки.

`SELECT c.contractor, s.id, s.date, s.sum`
`FROM (SELECT DISTINCT contractor FROM shipment) c`
`JOIN LATERAL (`
    `SELECT id, date, sum`
    `FROM shipment`
    `WHERE contractor = c.contractor`
    `ORDER BY date DESC`
    `LIMIT 3`
`) s ON true;`

Тип соединения таблиц скорее всего будет nested loop, т.е. для каждой строки из внешней таблицы будет loop по внутренней, но читать мы будем всего первые 3 записи. Это дешевле чем проходится оконной функцией по всем отгрузкам считая их порядковые номера а потом брать первые 3 но только при наличии индекса на внутренней таблице.
