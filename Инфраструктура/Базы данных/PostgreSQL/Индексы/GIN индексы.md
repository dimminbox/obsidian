Мы не можем использовать обычный b-tree индекс для JSON значений т.к. сам JSON состоит из множества значений. На помощь приходит специальный тип индекса - Generalized Inverted Index используется для хранения объектов, которые состоят из значений, например, JSON, элементы массива, тест, т.е. любые многоэлементные значения. Для JSON он хранит значения ключей json, который ссылаются на строки таблицы.
