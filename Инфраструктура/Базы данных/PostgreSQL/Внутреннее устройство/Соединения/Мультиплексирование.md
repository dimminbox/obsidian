
Postgres выполняет один запрос за раз пока соединение открыто, параллельно выполнять запросы в рамках одного соединения он не может. То есть соединение занято выполнением запроса и клиент не может послать запрос если все соединения заняты.

Для решения этой проблемы существует режим мультиплексирования, который позволяет сразу отправить несколько запросов в одно соединение, сам postgres будет их диспетчирезировать и отдавать результат клиенту.

Включается либо через ConnectionString либо через включение через драйвер:

`var builder = new NpgsqlDataSourceBuilder(connectionString);`
`builder.ConnectionStringBuilder.Multiplexing = true;`
`var dataSource = builder.Build();`
