После группировки значений мы можем обращаться к данными в этой группировке только через агрегатные функции, например, если группировка таблицы с колонками Id, Amount по Group by Amount, мы не можем обратится к Id, который соотвествует этому Amount. 
Для решения этой проблемы существуют оконные функции. Они не схлопывают строки как это делает GROUP BY, каждая строка остаётся в выдаче, они берут партицию данных которые сгруппированы по столбцу через PARTITION BY "Столбец" и могут выполнять с ними различные операции:
- получать порядковый номер ROW_NUMBER() OVER
- получить DENSE_RANK() OVER т.е. если два заказа имеют одинаковый Amount, то они получают одинаковый DENSE_RANK в отличие от ROW_NUMBER()
- RANK () даёт одинаковый ранг одинаковым значениям, то есть некоторые ранги могут быть пропущены
- LAG(col, N) берёт значения из поля col N - предыдущей строки
- LEAD(col, N) берёт значения из поля col N - последующей строки

Тут например получаем порядковый номер заказа из перечня заказов, отсортированных по сумме:

`SELECT Id, CustomerId, Amount,` 
`ROW_NUMBER() OVER (PARTITION BY CustomerId ORDER BY Amount DESC) as number` 
`FROM Orders`

Сами по себе оконные функции дешёвые, идут по отсортированным данным за один проход, но если нужно выполнить агрегатную функцию над ними, то они становятся дорогими.
