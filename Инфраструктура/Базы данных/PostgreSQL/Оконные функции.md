После группировки значений мы можем обращаться к данными в этой группировке только через агрегатные функции, например, если группировка таблицы с колонками Id,Amount по Group by Amount, мы не можем обратится к Id, который соотвествует этому Amount.

Для решения этой проблемы существуют оконные функции. Они берут партицию данных которые сгруппированы по столбцу через PARTITION BY "Столбец" и могут выполнять с ними различные операции:
- получать порядковый номер ROW_NUMBER() OVER 
- получить среднее значение AVG() OVER
- получить RANK() OVER т.е. если два заказа имеют одинаковый Amount, то они получают одинаковый RANK в отличие от ROW_NUMBER()
  
Тут наппример получаем порядковый номер заказа из перечня заказов, отсортированных по сумме:

SELECT Id, CustomerId, Amount, ROW_NUMBER() OVER (PARTITION BY CustomerId ORDER BY Amount DESC) as number FROM Orders
