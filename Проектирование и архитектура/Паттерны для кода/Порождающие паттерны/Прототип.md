
Паттерн, который решает проблему когда нужно быстро получить копию объекта. Любой класс, который реализовывает этот паттерн должен реализовывать интерфейс, который объявляет методы для создания мелкой и глубокой копий. Т.е. при создании объекта, особенно в случае если его инициализация занимает время, мы получаем его почти мгновенно т.к. просто клонируем используя один из двух методов.

Мелкая копия - это копия объекта где все поля ссылочного типа будут являться ссылками на поля оригинала. Для этого существует метод MemberwiseClone, который есть у типа object т.е. у всех типов. Он делает не глубокую копию и возвращает object, которые далее можно привести к нужному типу.

Глубокая копия - копия объекта где все поля ссылочного типа НЕ будут ссылаться на оригинал а будут ссылаться на новые переменные в куче.
