
Фабрика - это паттерн, который в зависимости от параметров создаёт объект. Тем самым забирая на себя обязанность по созданию объекта.

public class SimpleFabric
{
    public IClient Create(string type) => type switch
    {
        "email" => new SmtpClient(),
        "sms" => new SmsClient(),
    };
}

Абстрактная фабрика - это интерфейс, описывающий что должна делать абстрактная фабрика.

public interface INotificationFactory 
{
	 IClient CreateClient();
	 ITemplateEngine CreateTemplate(); 
 }

Далее, например, специальный класс провайдер по типу создаёт необходимую фабрику и уже дальше она создаёт необходимые классы, например, нужного Client для отправки уведомления.

Недостаток этой фабрики - это переписывание кода, если необходимо добавить новый метод в астрактную фабрику.
