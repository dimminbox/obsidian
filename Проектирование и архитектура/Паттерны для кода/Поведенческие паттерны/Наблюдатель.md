Поведенческие паттерн, который реалиует работу с классами через подписки. То есть он представляет из себя класс, который содержит метод Subscribe (или делагат Action) который нужно вызвать чтобы добавить подписчика на событие. Это может быть сделано явно через вызов метода подпичика либо через делагат Action, также он реализуем метод отписки. Сам наблюдатель не должен знать о подписчиках заранее, он всего лишь должен предоставлять возможность их добавить.

Он решает проблему, если заранее не известно какие методы нужно вызвать когда произошло какое - то действие, например, создание заказа. Также обеспечивает слабую связанность между классом - источником события и подписчиками.  Т.е. этот паттерн задает поведение источник - подписчик.
