
Это про организацию объектов в дерево. Это структурный паттерн предназначен для задач когда есть древовидные объекты и необходимо обойти все дочерние элементы рекурсивно чтобы получить результат для конкретного объекта, например, посчитать сумму стоимостей всех товаров во всех дочерних объектах для данного. Главное требование - чтобы узлы и листья (например, категории и товары) имели один интерфейс.
