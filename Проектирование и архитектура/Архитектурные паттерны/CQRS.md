
Command Query Responsibility Segregation  - архитектурный паттерн, которые отделяет чтение от записи и тем самым делает код более чистым, поддерживаемым и более масштабированным. Чтения и запись имеют разные требования, например, разная бизнесс - логика, транзакции, валидация у записи и скорость, денормализация данных, отсувтвие бизнесс - логики и прочее у чтения.

CQRS состоит из :
- Command - специальные классы для описания команд записи.
- Query - классы для описания запросов на чтение
- Handlers - классы, где commands или queries обрабатываются
- Behaviours - классы, которые выполняются до/после выполнения команды

Для того чтобы всё это работало как единое целое нужен медиатор, обычно это библиотека MediatR, который находит Handler и выполняет behaviour pipeline
